# AI Travel Concierge (Track A)

An intelligent travel assistant built with Python, LangChain, and Streamlit. The agent leverages tool calling to fetch live weather data and perform web searches for travel planning.

## Features
- **Conversational UI**: Interactive chat interface built with Streamlit.
- **Tool Calling Agent**: Dynamically invokes external tools based on user prompts.
- **Web Search**: DuckDuckGo API integration for real-time travel insights.
- **Live Weather API**: Fetches current temperatures and conditions using the Open-Meteo API.
